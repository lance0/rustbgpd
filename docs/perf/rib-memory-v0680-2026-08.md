# RIB memory v0.68.0 refresh — 2026-08-30

The full allocator-backed RIB memory campaign compared v0.67.0 commit
`69b27812eecc66e7affc505fbe887259b48990f5` with exact v0.68.0 commit
`d3e6c3571116261c47039b603ec64db14100ea0e`.

All twelve shared shape/size rows were byte-identical between releases. Those
rows cover Adj-RIB-In, full RIB with shared attributes, full RIB with diverse
attributes, and route-reflector fanout at 100,000, 500,000, and 900,000
prefixes.

Six representative-distribution rows were added for v0.68.0 only. They are
absolute measurements and are deliberately marked `missing-row`, not treated
as release deltas. The [compact artifacts](artifacts/rib-memory-v0680-2026-08/README.md)
retain all 18 rows and metadata.

This synthetic allocator measurement does not predict whole-daemon RSS or a
live-table footprint. Equality applies only to the twelve shared shapes.
