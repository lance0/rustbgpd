# High-N route-server v0.68.0 compact artifacts

The status, timing, and settled RSS summaries retain the exact-source 2,500-
and 5,000-peer runs. `provenance.env` records source and harness revisions,
`results.csv` reconstructs both headline rows, and `binary.env` records the
full daemon binary SHA-256. The original binary is not bundled, so this is not
a replayable binary package.
