# Shared stream retention: curated evidence

Supports [the receipt](../../shared-stream-retention-2026-11-07.md).

`comparison.json` contains exact source and binary identities, frozen bars,
eight per-leg medians for each timing cell, one row per memory leg (maximum
allocated bytes and VmHWM across the six phases, net bytes freed, required
release bytes, retention at End-of-RIB) and the memory summary. It preserves
the prior failed replica and invalid attempts. All campaigns ran locally;
there is no hosted run or public raw-log URL. Raw per-phase snapshots and logs
remain unchanged outside the published set.
