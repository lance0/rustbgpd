# Shared stream retention: curated evidence

Supports [the receipt](../../shared-stream-retention-2026-11-07.md).

`comparison.json` contains exact source and binary identities, frozen bars,
eight per-leg medians for each timing cell, six memory snapshots per leg,
and ownership/allocation results. It preserves the prior failed replica and
invalid attempts. All campaigns ran locally; there is no hosted run or
public raw-log URL. The raw logs remain unchanged outside the published set.
