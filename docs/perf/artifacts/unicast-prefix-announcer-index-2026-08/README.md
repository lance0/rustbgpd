# LAN-1034 announcer-index artifact

Run `python3 verify.py`, then `sha256sum -c SHA256SUMS` from this directory.
The verifier checks pinned identities, memory repeats and savings, campaign
admission, six paired observations per rung, the frozen Student-t calculation,
the +5% ceiling, summary agreement, and artifact integrity.

`memory.csv` is an isolated fresh-process allocator receipt. `paired-results.csv`
contains the 24 accepted A/B pairs from campaigns 3–5. `campaigns.csv` records
their 16/16 admitted cells and the excluded campaign 2 refusal. The original
campaign directories were `/tmp/lan1034-rr-run{2,3,4,5}-20260825`; the durable
manifest records hashes of their drivers and primary outputs.
