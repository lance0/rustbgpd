# RIB memory v0.68.0 compact artifacts

`results.csv` and `metadata.txt` are the complete compact output from the full
v0.67.0-to-v0.68.0 memory comparison. Twelve shared shapes are directly
comparable. Six representative-distribution shapes exist only at v0.68.0 and
are marked `missing-row`; they are absolute observations, not A/B deltas.
