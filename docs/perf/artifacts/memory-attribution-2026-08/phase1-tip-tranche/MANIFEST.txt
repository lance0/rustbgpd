QUIET-LANE / CONTAMINATION POLICY (= phase 0)
  Owner workloads (cargo/rustc plus unrelated resident services and
  containers) are never touched; cleanup filters strictly on bgperf-named containers +
  this campaign's own clones/images (ab1032-* tags only; the pre-existing
  current-cbefe848 image belongs to other phase work and is not
  touched). Lane verified before each pair (loadavg + ps by comm + top CPU
  snapshot); a resident idle service at ~zero CPU is acceptable, anything
  eating CPU pauses the campaign. Runs record lane-start/lane-end telemetry.
  Pairs overlapping foreign load are CONTAMINATED, excluded from the contract
  set, and replaced after the lane clears.
