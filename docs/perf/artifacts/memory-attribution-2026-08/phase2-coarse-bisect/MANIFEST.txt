PREREGISTERED DESIGN (frozen)
  - 5 runs per arm, 25 runs total, ROUND-ROBIN order
    (P1,P2,P3,P4,ANCHOR) x 5 -> r01..r25. Lane check before every run
    (loadavg + ps -C cargo,rustc by comm; recorded as lane-start/lane-end in
    every run log). Runs overlapping foreign load are CONTAMINATED, excluded,
    and replaced (r26+) after the lane clears.
  - PRIMARY metric: cg memory.peak per-arm MEDIAN (phase 1 showed it ~2x
    tighter than settled anon). SECONDARY: settled RssAnon median
    (ptree_anon_settled), convergence time (total_s).
  - ATTRIBUTION RULE: an interval (adjacent-arm pair in TRUE order, plus
    A->P2 and P4->ANCHOR, with A fixed at its recorded 195.1 cg-peak median)
    OWNS growth when its median cg-peak step is >= +25 MiB. Steps within
    +/-15 MiB are FLAT. Between (+15, +25) = MINOR CONTRIBUTOR, reported
    without ownership claim. Negative steps beyond -15 reported factually as
    reductions.
  - CROSS-CAMPAIGN ANCHOR: report ANCHOR's in-campaign medians vs its two
    priors (283.6/239.7 phase 0 n=15; 274.4/227.6 phase-1 n=7) as the
    campaign offset; NO correction applied, disclosure only.
  - SUM CHECK: the A->ANCHOR chain of median steps must be reconciled against
    the measured endpoint delta (+88.5 MiB cg peak = 283.6 - 195.1);
    unexplained residual reported as such (by construction the residual
    equals the anchor offset; stated explicitly either way).
  - ANOMALY TRIPWIRE: any run >= 40 MiB below its arm's RUNNING median (over
    that arm's runs so far, including it) on cg peak or settled anon ->
    preserve smaps/smaps_rollup pre-teardown and continue; the run is KEPT
    (known glibc arena low mode; medians absorb it). smaps are captured for
    EVERY run post-bench regardless, so preservation is automatic.
  - For any OWNING interval <= ~30 commits, the report includes the verbatim
    `git log --oneline --first-parent` list of that interval.
