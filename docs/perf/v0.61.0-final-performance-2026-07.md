# v0.61.0 final performance baseline — 2026-07

This receipt freezes an absolute performance baseline for the v0.61.0
release candidate at commit `99ee74ba67ec24ce8e09c0c18a83b652da35712b`, tree
`c6ef0d7da50b8be28ff62b8edb749f0fae0bd21f` (measured pre-tag; the final
v0.61.0 tag landed 87 commits later at `c7066575`). It is a release reference,
not an A/B optimization receipt: there is no CPU delta claim, and it does not
replace the historical cross-stack or explain-cache comparisons.

## Real-daemon route-server baseline

Three accepted runs used the real release daemon and 1,000 real loopback eBGP
clients, each originating 400 BASE routes (400,000 total). Import-decision
explain was disabled, reload count was zero, and all clients formed one
1,000-member update group. Every run reached 1,000/1,000 Established sessions,
the ≥399,600-announcement convergence gate for every observer, zero parse
errors, one group, zero fallback peers, zero residue, 1,000 registered outbound
peers, zero retained rejected routes, and zero settled writer-queue depth.

| Run | Cold gate | Steady process-tree RSS median | jemalloc allocated | active | resident | mapped |
|---|---:|---:|---:|---:|---:|---:|
| A | 8.03 s | 452,362 KiB (441.760 MiB) | 452,730,408 B | 468,856,832 B | 492,425,216 B | 512,745,472 B |
| B | 7.81 s | 451,804 KiB (441.215 MiB) | 445,213,640 B | 461,025,280 B | 485,408,768 B | 504,901,632 B |
| C | 8.46 s | 451,718 KiB (441.131 MiB) | 455,113,584 B | 470,892,544 B | 494,526,464 B | 514,838,528 B |

The three steady RSS medians have min/median/max
451,718/451,804/452,362 KiB (441.131/441.215/441.760 MiB). Allocated bytes
have min/median/max 445,213,640/452,730,408/455,113,584; active
461,025,280/468,856,832/470,892,544; resident
485,408,768/492,425,216/494,526,464; and mapped
504,901,632/512,745,472/514,838,528. RSS is the median of the retained 1 Hz
process-tree samples after convergence. The allocator columns are
point-in-time in-process gauges. They measure different quantities and are
deliberately reported separately.

The runs used the existing control-window harness after the cold gate. This
receipt makes no reload, policy-transition, explain-query, IPv6, Add-Path, VPN,
heterogeneous-policy, cross-host, or competitor claim. It also does not compare
these absolute values causally with older runs whose gates or source revisions
differ.

## Single-revision Criterion baseline

The named `v0.61.0-final-99ee74ba` archive covers 71 rows from the maintained
RIB, wire-codec, and policy suites on logical CPU 8. It records one revision,
so the values below are regression anchors rather than evidence that this
revision is faster or slower than another.

| Suite | Shape | Median point estimate [95% CI] |
|---|---|---:|
| RIB | `adj_rib_in_insert/10000` | 627.86 µs [627.48, 630.21] |
| RIB | `bulk_initial_load/100000` | 27.564 ms [27.529, 27.806] |
| RIB | `rib_pipeline/10000` | 3.591 ms [3.582, 3.626] |
| RIB | `route_churn/10k_base_1k_churn` | 283.08 µs [282.74, 283.31] |
| RIB | `export_policy_eval/lazy_as_path_string` | 239.25 µs [234.57, 314.15] |

| Wire | `update_parse_revised/500` | 3.161 µs [3.132, 3.212] |
| Wire | `update_parse_revised/ipv6_mp_add_path` | 179.52 ns [179.21, 180.42] |
| Policy | `policy_chain_eval/32` | 374.64 ns [374.26, 375.73] |

The compact artifact table retains the exact median point estimate, median 95%
confidence interval, sample count, and sampling mode for all 71 rows. The RIB
suite contributes 18 rows, the codec 28, and policy evaluation 25.

The measurement orchestration rejected an earlier collection after observing
swap-in advance by 1,377 pages during the run. The excluded directory did not
retain its own before/after page counters, so the compact rejection record
documents that decision; it is not independent evidence from which the delta
can be replayed. None of the excluded attempt's estimates or medians are used
or retained. Before the accepted retry, the host's dedicated swap file was
cycled to zero use; the accepted receipt is self-contained and has byte-equal
swap page counters before and after all three suites. That is host preparation,
not a performance result.

## Environment and acceptance

- AMD Ryzen Threadripper 7970X, 32 cores / 64 threads, 125 GiB RAM.
- Linux 6.17.0-35-generic; rustc 1.97.0; cargo 1.97.0.
- All 64 CPU governors reported `performance`; route runs admitted no competing
  workload and no swap I/O before or after the release build.
- Criterion was pinned to logical CPU 8.
- The route-server run required a clean, source-stable worktree, positive
  release-build jemalloc gauges, successful harness/sampler exit, and the exact
  settled operational gates listed above.
